# Как показать работу преподавателю в реальном времени

## Вариант 1 — живой демо-скрипт (рекомендуется)

На этом компьютере всё уже установлено и собрано. Просто запусти пошаговую
демонстрацию:

- **Двойной клик по `demo.bat`** (или правый клик → «Запуск от имени…» не нужен),

либо в PowerShell из папки проекта:

```powershell
powershell -ExecutionPolicy Bypass -File demo.ps1
```

Скрипт идёт по 7 шагам и ждёт нажатия **Enter** перед каждым — ты комментируешь,
преподаватель видит реальный вывод:

1. справка по инструменту;
2. вычисление хэша (`123456` → совпадает с хэшем из задания);
3. подбор **MD5** — доли секунды, ~3 млн хэшей/с;
4. подбор **bcrypt** — десятки хэшей/с (разница в десятки тысяч раз);
5. эталон **John the Ripper** — MD5 и SHA-1;
6. эталон **John** — bcrypt (16 потоков OpenMP);
7. эталон **hashcat** — Argon2id на GPU (RTX 3050).

Весь прогон укладывается в 2–3 минуты.

## Вариант 2 — отдельные команды вручную

Если нужно показать конкретный запуск, из папки проекта (пути к Java/John/hashcat
прописаны в `demo.ps1`):

```powershell
# свой инструмент
java -Dstdout.encoding=UTF-8 -cp "out;lib/*" ru.mirea.bruteforce.Main crack --algo md5 --hash e10adc3949ba59abbe56e057f20f883e --charset digits --max 8

# John
& "C:\Claude pr\tools\john\john-1.9.0-jumbo-1-win64\run\john.exe" --format=raw-md5 --mask='?d?d?d?d?d?d' "C:\Claude pr\tools\hashes\md5.txt"

# hashcat (Argon2id на GPU)
cd "C:\Claude pr\tools\hashcat\hashcat-8.0.0"
.\hashcat.exe -m 34000 -a 0 -d 1 a2\h1.txt wl_test.txt
```

## Вариант 3 — через IntelliJ IDEA

Открыть проект (`File → Open` → папка `semestrovoe-3`, IDEA подхватит `pom.xml`),
затем запустить класс `ru.mirea.bruteforce.Main` с параметрами в конфигурации
запуска (Run → Edit Configurations → Program arguments), например:
`crack --algo md5 --hash e10adc3949ba59abbe56e057f20f883e --charset digits --max 8`.
Наглядно показывает исходный код рядом с результатом.

## Если спросят «а сложные пароли?»

Честный и правильный ответ: «сложный» и «очень сложный» пароли на bcrypt/Argon2
полным перебором на этом железе за разумное время **не вскрываются** — это и есть
доказательство стойкости адаптивных алгоритмов. Именно поэтому их применяют для
хранения паролей, а MD5/SHA-1 — нельзя.
